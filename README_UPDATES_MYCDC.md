# Pembaruan MY CDC GATSU

## Harga resmi
- Selain Mentai dan Ori: Ayam + Saus Rp12.000; Ayam + Saus + Nasi Rp16.000.
- Mentai: tanpa nasi Rp14.000; dengan nasi Rp18.000.
- Ori: tanpa nasi Rp10.000; dengan nasi Rp13.000.
- Extra Saus: Rp2.000. Nama saus dapat diketik manual saat pemesanan.
- Extra Nasi: Rp4.000.

## QR Member di Admin
Buka `/admin/members`, lalu tekan **Scan QR Member**. Scanner kamera menggunakan QR yang sudah tampil di kartu member. Jika browser tidak mendukung scanner kamera, tersedia input Member ID manual sebagai fallback.

## Sitemap Google
File SEO tersedia di:
- `/sitemap.xml`
- `/robots.txt`

Sitemap publik sengaja hanya berisi halaman yang layak diindeks. Halaman admin, checkout, profil, chat, dan riwayat pesanan tidak dimasukkan karena bersifat privat.

### Google Search Console
Tambahkan properti domain/URL `https://www.dicelupayamcrispy.store`, lalu buka menu **Sitemaps** dan kirim:

`https://www.dicelupayamcrispy.store/sitemap.xml`
